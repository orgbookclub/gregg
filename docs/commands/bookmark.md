# Bookmark

This command is for bookmarking messages on Discord.

## Usage

Unlike slash commands, this is a context command. Right-click on any message and select **Apps → Bookmark**. The bot will DM you a copy of the message with the source server name, channel mention, message content, attachments, and any stickers — alongside two buttons:

- **Jump to Message** — opens the original message in the source channel.
- **Delete** — removes the bookmark from your DMs.

!\> **IMPORTANT**: You must have DMs from server members enabled for the bot to message you.
